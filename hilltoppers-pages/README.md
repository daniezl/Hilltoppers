# Hilltoppers Pages Data

Static data served via Cloudflare Pages at `hilltoppers.pages.dev`.

### Data Files
- [special_days.json](./data/special_days.json) — Schedule overrides for specific days
- [special_periods.json](./data/special_periods.json) — Breaks / holidays
- [menu.json](./data/menu.json) — Dining hall menu (auto-updated every 30 min)
